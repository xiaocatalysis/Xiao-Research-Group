## Root cause (confirmed byte-for-byte)

`Members.html` == `Header.html` + `Header.html` + `Footer.html` and `Publications.html` == Header x3 + Footer x2, exactly. `php Biography.php > Biography.html` truncates the content fragment `Biography.html` before PHP includes it, so PHP re-reads its own partial output (the header). Replaying the same loop on a replica repository reproduced identical 21 772-byte files with the same MD5 (a45891e9...).

## Other findings
- No root-relative paths (`/assets/...`) anywhere: relative links work at both the github.io project URL and www.xiaocatalysis.com.
- Visitor counter and visitor map are third-party JS widgets in iframes; `Count_Visitor/Count_Visitor.php` is not referenced by Header/Footer.
- fix_recsl_links.py changed external links too (example above), which is why regex replacement across all files is unsafe.
